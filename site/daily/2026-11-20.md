## 3. JEPA as a Transferable Optimizer: Learning and Understanding Black-Box Optimization from Reward-Agnostic Pretraining

`相似度 4.043` ｜ Mayukh Debnath, Manan Roy Choudhury

**论文速览**：暂未生成，请参考原始摘要和原文。

<details>
<summary>原始摘要</summary>

> Black-box optimization evaluates candidates through simulations, rollouts, or experiments, often without gradients. Learned optimizers are usually judged by whether they outperform existing methods. We ask a complementary question: what information does a learned optimizer use from its search history? We introduce JEPA-PS (JEPA Policy Search), based on a Joint-Embedding Predictive Architecture. It is pretrained on random rollouts using parameter vectors and scalar returns. Its latent-prediction objective predicts the next point in an optimization trajectory rather than its reward or gradient, allowing us to examine what was tried and how well it performed. Our main finding is that the history JEPA-PS uses depends on the task. On smooth landscapes it uses the full trajectory, whereas on rugged landscapes the best-seen point carries nearly all the signal. This memory requirement has a weak positive correlation with fitness-distance correlation (FDC; r=0.112, n=7), while an independent reward-ordering sensitivity probe does not corroborate the relationship (r=-0.024, n=7). ## 5. GRAFT: Execution-Guided Genetic Recombination for Agent Design

`相似度 3.878` ｜ Sevda Ebrahimi, Mohammed Saidul Islam, Xiaodan Zhu, Elham Dolatabadi ｜ Queen's University; Vector Institute; York University

**研究问题**：自动化LLM智能体设计中,进化搜索通常仅靠聚合适应度引导,掩盖了每个分数背后的实例级成败信息。

**方法**：GRAFT以聚合适应度负责选择与存活,以父代专属执行证据引导语义交叉并集成变异,复用有界成败样本且无需额外任务执行。

**方向关联**：与画像中'LLM与进化计算交互值得重点关注'直接契合:用交叉、变异、适应度等进化算子进化LLM智能体架构,且不涉及分布式多智能体进化计算,属主线交叉而非辅助方向。


<details>
<summary>原始摘要</summary>

> Automated agent design searches for executable architectures that improve LLM-based agent performance, with evolutionary methods using language-model crossover to recombine promising mechanisms for task decomposition, model coordination, and verification. This search, however, is typically guided by aggregate fitness alone, which hides the instance-level successes and failures behind each score. We introduce Execution Guided Genetic Recombination for Agent Design (GRAFT), which uses aggregate fitness for selection and survival and parent-specific execution evidence to guide semantic crossover with integrated mutation. It achieves a mean test accuracy of 82.0%, exceeding the strongest baseline by 9.8% points. Controlled ablations show that adding execution evidence improves test accuracy with initialization, search rules, repair policies, and evaluation budgets held fixed. Our results support the value of parent-specific execution evidence for evolutionary agent design.

## 6. Option-GRPO: Hierarchical RL Against AI Slop in Code Generation for Unseen SDKs

`相似度 3.838` ｜ Prashank Kadam ｜ Cerby Inc.

**研究问题**：让代码LLM仅凭SDK源码适应训练截止后发布的未见SDK，无需人工示例与测试，并同时优化功能正确性与代码简洁性。

**方法**：从SDK源码构图发现可复用代码选项，作为课程与动作空间，逐级用GRPO结合执行奖励训练分层策略。

**结果与证据**：论文报告：12个未见SDK上32B模型pass@1达61.4%，超flat GRPO 8.7分；API调用少34.7%，代码短27%。

**方向关联**：与LLM/API支线直接契合（LLM适配未见SDK/API），但优化采用分层强化学习而非进化计算，二者交互体现较弱。

**代码复现线索**：所供文本给出32B基座、12个未见SDK（如Daft、LanceDB）、分层执行校验加属性测试奖励及推理温度0.2/0.8，未见训练超参数。


<details>
<summary>原始摘要</summary>

> Large language models increasingly produce AI slop in generated code: verbose, redundant, non-idiomatic implementations that pass functional checks but bloat codebases. The problem compounds on SDKs released after the model's training cutoff, where the model has neither idiomatic priors nor compositional understanding. We present Option-GRPO, a hierarchical reinforcement learning framework that adapts a code LLM to an unseen SDK from its source code alone, without human-written usage examples or test cases, and that explicitly optimizes for both functional correctness and code elegance. Our key insight is that SDK source code contains compositional structure that defines a hierarchy of reusable code patterns (code options) which simultaneously serve as the building blocks of a curriculum and the action space for efficient policy optimization. We show that code options induce a valid semi-Markov decision process, give conditional bounds under which shorter option description length implies more concise and, in expectation, more API-efficient programs, and analyze under stated assumptions how the option hierarchy improves credit assignment by a factor of $\sqrt{T/K}$. Using Group Relative Policy Optimization (GRPO) with execution-based rewards at each curriculum level, Option-GRPO discovers SDK idioms, composes them into patterns, and assembles patterns into complete programs. Experiments on 12 unseen SDKs with a 32B-parameter base model demonstrate 61.4% pass@1, outperforming flat GRPO by 8.7 points, ExploraCoder by 11.2 points, and ReCode by 6.3 points. Option-GRPO produces solutions that use 34.7% fewer API calls and are 27% shorter than flat-GRPO outputs while maintaining higher correctness, directly attacking the slop problem.

</details>

## 7. Agentic Harness Engineering Beta: Requirement-Centered Evolution of Agent Harnesses

`相似度 3.756` ｜ Jiahang Lin, Jiahao Chen, Yiding Wang, Shichun Liu, Chengjun Pan, Shihan Dou et al. ｜ Shanghai Qiji Zhifeng Co., Ltd; Fudan University; Renmin University of China

**研究问题**：现有代理 harness 进化忽视隐式用户需求，依赖基准分数选择改动，易产生窄补丁并陷入基准特定局部最优。

**方法**：AHE-Beta 让模拟用户多轮交互提出 issue，多角色团队（Triage、架构师、PM、开发者）实施通用改动，仅当需求被验证且评审通过才合并。

**结果与证据**：held-out 任务 pass@1 从 21.9% 升至 33.3%，token 省 40.8%，并免再进化迁移至 GLM-5.3 提升 15.8 个百分点。

**方向关联**：直接契合 LLM/API 支线：面向 LLM 编码代理的自动化 harness 进化；其生成-验证-选择迭代循环与进化计算的进化思想有交互参考价值。

**代码复现线索**：评估基于 Harbor-index held-out 任务；论文中 harness 代码存放于 Gitea 仓库，固定底座模型仅进化周边 harness。


<details>
<summary>原始摘要</summary>

> Real-world harness engineering is driven by explicit and implicit user requirements, which guide development and validation. However, existing harness evolution methods often overlook implicit requirements and interaction needs, while using a single evolution agent to modify the harness and benchmark scores to select changes. This process often produces narrow patches and leads to benchmark-specific local optima. We introduce Agentic Harness Engineering Beta (AHE-Beta), a requirement-centered loop that brings real-world engineering practices into harness evolution. The loop consists of three steps: (1) User-driven evaluation lets simulated users raise their requirements as issues while they work with the harness over multiple turns. (2) Team-based modification implements those requirements as generalizable changes rather than task-specific patches. (3) Requirement-driven selection merges a change only when it resolves a verified requirement and passes review. Empirically, on held-out tasks, AHE-Beta raises pass@1 from 21.9% to 33.3% while using 40.8% fewer tokens than Base Harness, and achieves higher pass@1 than Claude Code, Meta-Harness, and AHE. In a blind human A/B test, real users prefer AHE-Beta in 31 of 48 valid pairs and rate it higher on all five dimensions, matching the directional preference of the user simulator. The human A/B results show that AHE-Beta achieves its goal of aligning harness evolution with real-world user requirements. Without further evolution, the gains transfer to GLM-5.3 and DeepSeek-V4.1-Flash with pass@1 improvements of 15.8% and 5.3% over Base Harness. Together, these results show that requirement-centered harness evolution is a more general method for improving agent capabilities.

</details>

## 8. Meta-LSQ: A Closed-Form Sobolev Inner Solver for Few-Shot Meta-Learning

`相似度 3.641` ｜ Antonin Sulc ｜ Lawrence Berkeley National Laboratory

**研究问题**：针对MAML类元学习器需对内循环梯度下降做二阶反传且元学习全部权重的问题，研究用闭式求解替代内循环的少样本元学习。

**方法**：在固定随机傅里叶基上做一次正则化最小二乘拟合每个任务，仅元学习带宽、岭、导数权重三个标量，导数观测可线性并入同一方程组。

**结果与证据**：10样本正弦回归14秒训练、误差较一阶MAML低5.5倍；ARES束流仿真最佳设置中位误差7.3μm优于RL智能体的14.4；非平滑目标上失效。

**方向关联**：与进化计算/群智及LLM/API两条支线均无直接重叠，属少样本元学习与闭式优化方法，与当前阅读主线关系较弱。

**代码复现线索**：论文正文说明，支撑文中所有数字与图表的代码及存储结果均已随论文公开。


<details>
<summary>原始摘要</summary>

> Gradient-based meta-learners such as model-agnostic meta-learning (MAML) adapt to a new task with an inner loop of gradient descent that has to be differentiated through, and they meta-learn every network weight. Meta-LSQ instead fits each task with one regularised least-squares solve over a fixed random Fourier basis and meta-learns only three scalars, a bandwidth, a ridge and a derivative weight. Since the derivative of a sinusoid is again a sinusoid, the same solve can also take derivative observations, and the fitted model has exact closed-form derivatives of any order. On 10-shot sinusoid regression Meta-LSQ trains in 14 s and ends with a 5.5 times lower error than a first-order MAML baseline that trains 36 times longer, and a Gaussian-process control suggests that most of this gain comes from sharing one kernel across tasks. In simulated beam tuning at DESY's ARES facility with model derivatives it is slightly more accurate than an ALPaCA-style model and well ahead of gradient descent. Over DESY's full range of target beams, again in simulation and from measurements alone, its best setting has a median error of 7.3 $\mu$m, against 14.4 for the published final beams of their reinforcement-learning agent, which has the lower median on their 300 trials of small targets. On real sensor-calibration data a learned prior mean puts it ahead of MAML on two of four targets, but an exact Gaussian process with the same change and an ALPaCA-style model stay more accurate on most targets, and it breaks down on non-smooth targets. On noiseless targets outside the span of the basis, in-sample criteria such as generalised cross-validation choose too small a ridge.

</details>

## 10. A Differential Theory of Quality-Resource Trade-offs for AI Model Selection: The Multiresource Frontier and Its Minimax Price

`相似度 3.604` ｜ Dmitry Ignatov ｜ University of Würzburg

**研究问题**：针对偏移幂律拟合无法揭示前沿的价格无关几何与多资源权衡，发展AI模型选择的质量-资源权衡微分理论。

**方法**：将前沿归约为 N\_eff=s²/κ 对 ΔS 的平面曲线，由完全单调性与可分性导出微分不等式、运行规则 N\_eff=1 及价格 λ\*\_i=α\_i/\(N+1\)。

<summary>原始摘要</summary>

> Video evaluators play an important role in video generation, yet they miss motion defects, limiting the quality of generated videos. Recursive self-improvement (RSI) has made strong progress in mathematics and coding, where explicit verifiers provide reliable feedback on a single goal. Video evaluation poses two difficulties for RSI: it has no verifier, and it must judge many dimensions at once, such as physics, smoothness and dynamics, where a gain on one can cost another. We introduce EVA-RSI, a multi-agent framework for exploring RSI under these two constraints. We build a fixed proxy exam with construction-defined targets by applying controlled changes to videos, such as temporal reversal and frame dropping. These edits supply supervision without human annotation. A small set of human-labeled real videos anchors the exam to human judgment. Each dimension has an LLM agent that proposes improvements. A leader agent coordinates the proposals, and a Nash bargaining rule selects updates that balance progress across dimensions. Humans design the exam, review candidate changes and revise the curriculum between stages. Starting from Qwen3-VL-8B, EVA-RSI improves motion evaluation, with the largest gain on smoothness, and the gains carry over to defect types never seen during the run. On the dynamics subsets of public benchmarks, our evaluator achieves the highest observed scores among 21 tested models. As an RL reward, it increases generated motion and earns human preference. A data-selection pipeline incorporating it also increases motion.
