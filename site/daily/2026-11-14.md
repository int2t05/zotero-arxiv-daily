<details>
<summary>原始摘要</summary>

> Modern automated heuristic discovery (AHD) systems increasingly rival hand-crafted heuristics by leveraging Large Language Models (LLMs) to iteratively mutate and refine solutions. A natural assumption is that more powerful and more expensive models consistently yield better heuristics. We challenge this empirically: across multiple NP-hard combinatorial optimization problems, we find no consistent advantage for larger, costlier models. This raises a deeper question: given a pool of LLMs spanning frontier and freely hosted or open-weight models, how should one adaptively select which model to invoke at each step of the search? Across five NP-hard combinatorial optimization problems and a pool of four models of varying capability and cost, Ballad not only matches the best individual LLM in hindsight but, in several cases, surpasses every individual model while reducing API cost by up to 65.6% relative to always using the strongest model.

Since its inception two decades ago, CGP has predominantly been analyzed empirically, thus little is known regarding its theoretical performance guarantees. ## 99. SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models

`相似度 3.124` ｜ Lichen Li, Ziping Dong, Sicheng Feng, Qi Li, Xinchao Wang

**研究问题**：现有基准对系统一模型的能力广度与决策可靠性刻画不足，需要超越聚合准确率的系统化评估。

**方法**：提出 SO-Arena 基准，跨 11 个领域与五类能力族，用证据核验、难度分层与沙盒交互评估能力，用选项重排稳定性与缺答识别衡量可靠性。

**结果与证据**：对 21 个模型的评测显示：规模与额外推理的收益因领域差异显著，且整体表现最好的系统一模型可靠性仅排第七。

**方向关联**：契合 LLM/API 支线：为快速决策型 LLM 提供能力谱与决策可靠性的评估范例，可作模型评测方法参考；但与进化计算无直接交集。

**代码复现线索**：论文正文列出项目主页、Hugging Face 与 GitHub 资源入口；评测覆盖 21 个模型，稳定性测量涉及其中 19 个，所给文本未含更多实现细节。

<summary>原始摘要</summary>

> System One models promise fast, general-purpose decision-making without lengthy token generation. However, understanding their capability spectrum and decision reliability requires more than aggregate performance on current benchmarks. Existing evaluations often provide limited insight into the breadth of model capabilities and the reliability of their decisions. We introduce SO-Arena, a benchmark characterizing the capability spectrum and decision reliability of System One models across 11 domains and five capability families. For the capability spectrum, SO-Arena offers evidence-grounded evaluation through reliable sources and manual verification of reference labels against model-visible inputs; fine-grained capability assessment through domain-specific difficulty criteria; and realistic interactive evaluation, where models iteratively execute actions in sandboxes. Reasoning-intensive tasks further enable system one-two comparison. Beyond accuracy, SO-Arena assesses decision reliability through two complementary measures: decision stability under controlled option-set changes and missing-answer recognition when no valid option is available. Evaluations across 21 models reveal that the benefits of scaling and additional reasoning vary substantially across domains. More importantly, strong overall performance does not necessarily imply reliable decision-making: the best-performing System One model ranks only seventh in reliability. Together, these findings highlight the need to characterize capability spectrum and decision reliability as complementary dimensions, providing a systematic view of the strengths and limitations of System One models.

## 100. Metal Sandbox: Isolated Execution and Command Scheduling for GPU Coding Agents on Apple Silicon

`相似度 3.120` ｜ Haozhe Wang, Lina Chen, Fanqi Wan, Qi Han, Yinmin Zhang, Zheng Ge et al.

**研究问题**：在 Apple Silicon 上训练与评估生成 Metal 内核的编码智能体时，rollout 过程 GPU 大量空闲，需要隔离执行与命令调度。

**方法**：提出 Metal Sandbox：每实例受限文件访问、原生命令执行、跨 Mac 命令级调度与等待命令迁移，并与 Harbor 集成支持任务执行、自动验证和 rollout 收集。

**结果与证据**：四台 Mac mini M4 集中负载下命令吞吐提升 1.68–2.05 倍；16 条静态轨迹估计持续吞吐 2.14 倍，回放显示工具等待降 18.8%、批耗时降 22.3%（均带未变时长等假设）。

**方向关联**：与 LLM/API 支线部分重叠：属面向 LLM 编码智能体的本地推理与工具执行基础设施；但无进化计算或群智算法内容，与主线及 LLM×EC 交互无直接关联。

**代码复现线索**：论文称对照实验在四台 Mac mini M4 节点进行，用 16 条静态智能体轨迹回放评估，Metal Sandbox 与 Harbor 集成在 GitHub 开源。


<details>
<summary>原始摘要</summary>

> On-device inference requires kernels that make effective use of local accelerators. Efficient training and evaluation of models that generate Apple Metal kernels benefit from native macOS tools and concurrent agent sessions. These sessions alternate between model requests, development commands, and GPU execution, leaving GPU capacity idle for much of a rollout. We present Metal Sandbox, infrastructure that combines restricted per-instance file access, native command execution, and command-level scheduling across interconnected Macs. Each agent retains its workspace and private development environment. Parallel commands can run concurrently, while serial commands share one execution slot per node; eligible waiting commands can migrate to available Macs and return results to the original agent. Integration with Harbor supports task execution, automatic verification, and rollout collection through a common workflow. Controlled experiments on four Mac mini M4 nodes achieve $1.68\times$--$2.05\times$ gains in command throughput under concentrated demand. Sixteen static agent traces give an estimated $2.14\times$ sustained-throughput gain for four sessions per node versus one, assuming continuously replenished sessions and unchanged mean durations. Replaying these measured traces under dynamic scheduling reduces mean tool waiting by 18.8% and batch elapsed time by 22.3%, assuming unchanged phase durations. Metal Sandbox and its Harbor integration are open-source on GitHub.
